# Sponsor Overlay

ストリーミング用のシンプルなスポンサーメッセージオーバーレイです。

## 概要

- `index.html` で表示するシンプルなオーバーレイ
- `style.css` で透明背景とアニメーションを実現
- `script.js` でスポンサー文言を3秒ごとに切り替え

## 特長

- 透過背景対応
- OBSや配信用ブラウザソースと相性が良い
- 表示位置は右下固定
- メッセージはフェードイン/フェードアウトで切り替わる

## ファイル構成

- `index.html` - オーバーレイ本体
- `style.css` - 見た目のスタイル
- `script.js` - メッセージの切り替えロジック

## 使い方

1. `index.html` をブラウザで開く
2. OBSなどの配信ソフトでブラウザソースに追加する
3. ブラウザソースの透明背景を有効化する

## カスタマイズ

- `script.js` の `sponsors` 配列に任意の文言を追加・変更
- `style.css` のスタイルを変更して見た目を調整
- `setInterval` の時間を変更して切り替え間隔を調整

## 例

```js
const sponsors = [
  "Xperia 1 VI で映像制作をもっと快適に",
  "Apex Legends で一緒に勝ちに行こう",
  "新作ゲームの最新情報をチェック",
  "次の配信もお楽しみに"
];
```
